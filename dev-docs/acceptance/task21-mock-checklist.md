# Task 21 收尾人工验收清单（Mock）

2026-10-19 由 Claude 整理、用户确认存档。用户选择方案 A：先由 GPT 实现仅本地显式启用的 `SEARCH_PROVIDER=mock` 开关（提示词见 [prompts/task21-mock-search-switch-gpt.md](../prompts/task21-mock-search-switch-gpt.md)），经 Claude 复核后再执行本清单。标 ★ 的项依赖该开关。本清单不调用真实 Tavily / Gemini，不访问 VPS，不构成 Task 22 真实验收。

## 0. 前提与已知限制

- 开关未交付前，运行中的应用里每次搜索都会降级为 `unavailable`；★ 项须等开关复核通过后执行。
- **Z1（低，仅开发模式）**：不要用 `npm run dev`（Vite）验收。Vite 代理会删除浏览器请求的 `Origin` 头，使浏览器请求看起来是"本机且无 Origin"，可在请求体声明 `discordUserId` 并访问 Discord 会话接口（ADR-014 起已存在）。生产方式由 Express 直接提供页面，不受影响。
- **已知差异（按现状验收，不算不通过）**：
  - **D12**：停止生成后 Web 保留已生成片段，末条回复无法重试（用户决定暂不授权）。
  - **Y1**：Discord 来源中偶数个连续 `*` / `_` 会漏转义末尾一个，可能出现斜体。

## 1. 环境准备

| 步骤 | 做法 | 目的 |
